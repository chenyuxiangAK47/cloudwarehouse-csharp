Waybill Import

Upload waybill Excel — auto weight rounding, receivable/payable/profit calculation; supports legacy dual-header billing sheets for transit fee verification. Preview before commit or export results.

Upload Excel

Download the standard template first (bill date, waybill no., account name, destination province, settlement weight, etc.). Also supports legacy dual-header billing detail sheets (billing + cost detail): reads manually entered transit fees and compares with system calculation. Upload a single-sheet file (not a multi-sheet billing workbook). Rounding: ≤0.3→0.3, ≤0.5→0.5, ≤5→round up to whole kg (e.g. 2.19→3). Receivable matches customer quotes by customer code or account name; payable uses cost price + destination province.
