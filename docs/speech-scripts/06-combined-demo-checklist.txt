## 现场点击路径（约 2 分钟）

1. **Login**
   - 粘贴员工码 → **Apply Code & Login**（或 Login）
   - Line 应出现 Gear Line
2. **选机**
   - 输入/确认设备 **GH01**，或手选 Hobbing Cluster → 机床
3. **Start**
   - Batch No.：`BATCH-DEMO-001`
   - Drawing / Process：`Q26-W830E102.040` + `Turn-Mill`（或组合码）
   - 提交 → 看到 **Start succeeded**
4. **Report**
   - 同一机台报工 → 看到 **Report succeeded**

要让老师看到的点：
- 无正式工单也能开工报工
- 扫码/手输批号与图号工序
- 报工机台对齐开工机台
